## Variant: Adventure Map

### Design stance
The village becomes a game board — buildings placed along a winding golden path over a deep-night sky. Play-first, exploration-led (Duolingo-path meets Animal Crossing).

### Key choices
- Layout: full-bleed map; 6 building nodes on a dashed animated path; quest banner + legend below
- Typography: Baloo 2 display, Nunito body, uppercase eyebrow labels
- Color: DeepNight (#0B2A36) base, glowing node halos, gold path + gold XP text
- Interaction: click a building → lesson modal; locked building (Kindness Corner) shows 🔒 "Reach Lv 4"; twinkling star field

### Trade-offs
- Strong at: motivation, clear "one path at a time" guidance, sense of progress and reward
- Weak at: fewer subjects visible at once; dark theme is a departure from the current light village
- Watch out: node positioning must be tuned per screen size — absolute placement doesn't auto-flow

### Best for
- Turning daily learning into a quest; great for reluctant starters who want the games
