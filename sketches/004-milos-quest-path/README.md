## Variant: Milo's Quest Path

### Design stance
The Duolingo treatment: one winding lesson path, streak/XP/gems/hearts HUD, chunky 3D buttons, mascot with speech bubble. Motivation is the product.

### Key choices
- Layout: vertical path of circular lesson nodes with alternating side labels; weekly chest milestone; right rail = Today's Quest
- Typography: Baloo 2 display, Nunito body
- Color: Duolingo-inspired green CTA (#58CC02) over neutral cream; subject nodes keep brand colors
- Interaction: current node pulses; CTA fires confetti; quest rows check off; nodes open lesson modal

### Trade-offs
- Strong at: habit formation — streak, hearts, gems give the daily loop emotional stakes
- Weak at: only ~6 lessons visible at once; path must scroll on longer units
- Watch out: vertical space is precious on a 3:2 landscape tablet — path length must be tuned per week

### Best for
- Keeping Maxine coming back daily; the closest match to what she may already know from Duolingo
