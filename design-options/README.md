# Maxine’s World Playroom refinement

The active design direction is a **polish of the current Playroom**, not a redesign.

Open the rendered review board at `index.html`, or use the direct sample:

- `refined-current/index.html` — interactive refinement
- `previews/refined-current-desktop.png` — desktop render
- `previews/refined-current-mobile.png` — mobile render

## Active flow

Greeting → resume learning → optional Tagalog videos → Today’s Quest → subjects → Milo’s Wildlife Sanctuary and sticker book → bottom navigation.

## Preserved

- Gold-to-coral Playroom background
- Cream surfaces, teal actions, subject accents
- Baloo 2 + Nunito typography
- Existing mascot, subject, reward, sanctuary, and sticker language
- Tactile rounded controls and parent boundary
- Child-safe, learning-first hierarchy

## Improvements

- The greeting and helper mascot establish arrival without competing with learning.
- Resume learning and Today’s Quest have clear action-led CTAs.
- Optional videos are discoverable but secondary.
- Subject cards use real artwork, formal subject names, playful labels, progress, and status.
- Sanctuary and stickers remain visible as reward/progress surfaces rather than navigation.
- Mobile uses the same hierarchy and keeps bottom navigation from covering content.

The village/map direction is **dropped from the active recommendation** because it does not match the current Playroom flow. Earlier experimental files remain in the workspace only as design history. No production Android/Compose code was changed.
